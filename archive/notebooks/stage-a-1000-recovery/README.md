# Stage A recovery experiments

These notebooks preserve the recovery and browser diagnostics for the fixed
1,000-URL Stage A pilot. They are archived for later review and are not part of
the active data pipeline. The active notebook folder contains only the four
pipeline notebooks: `00 → 01 → 02 → 03`.

Notebook 01g validates an exact 1,000-ID input and is not a general recovery
workflow for a million-URL run. Revisit missing-URL recovery after the baseline
reaches approximately one million URLs.
